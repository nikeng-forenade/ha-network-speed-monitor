# Network Speed Monitor

A Home Assistant Lovelace card with two live Top-10 rankings — download and upload — built from the
bandwidth sensors you already have. Animated bars, device icons, per-reading age, light/dark theme
support, display refresh control and a full visual editor.

```yaml
type: custom:network-speed-monitor
title: Network Speed Monitor
subtitle: Top 10 devices by download and upload speed
```

See [README.md](README.md) for installation via HACS, all options and troubleshooting.
